# Blinkit Sales Dashboard

## 📊 Project Overview

A Power BI dashboard developed to analyze Blinkit's sales performance and present key business insights through interactive data visualizations.

## 🛠️ Tools Used

- Power BI
- Excel

## 📈 Key Analysis

- Sales performance analysis
- Revenue analysis
- Product performance
- Regional sales analysis
- Key Performance Indicators (KPIs)
- Interactive filters and slicers

The Power BI `.pbix` file is included in this repository for reference.
